Cross-Domain Transferability of Deep Learning Intrusion Detection:
A Multi-Dataset Study with Domain Adversarial Training
M. Vikas Goud, Riteesh Thiruveedhula, Shaik Gafar, V. Sai Tarun Reddy
Department of Computer Science and Engineering -- AIML
KG Reddy College of Engineering and Technology, Hyderabad, India
{vikas, riteesh, gafar, tarun}@kgrcet.ac.in

Abstract—
Wireless intrusion detection systems trained on a single dataset report high accuracy but fail when deployed against traffic from different network environments. We measured this failure directly: a Random Forest trained on WSN-DS scored 99.6% on its own test set but dropped to 0.18% when tested on CIC-IoT-2023 traffic. This paper quantifies the cross-dataset domain gap across three wireless/IoT intrusion detection benchmarks using a 3×3 transfer matrix. Our experiments produced three findings. First, the hybrid deep learning model learns partially transferable representations: WSN-to-Edge transfer accuracy rose from 11.9% to 80.7%. Second, log-scale feature normalization had a larger effect on Edge-IIoTset accuracy than any architectural change, lifting same-dataset performance from 56.8% to 94.4%. Third, a two-domain DANN trained jointly on CIC-IoT and Edge-IIoT achieved 96.5% and 96.3% accuracy respectively.
Keywords— intrusion detection, cross-dataset transfer, domain adaptation, CNN-BiLSTM, self-attention, DANN, wireless security, IoT

I. Introduction

Wireless and IoT networks generate traffic that attackers exploit through jamming, spoofing, denial-of-service flooding, and reconnaissance probing. Intrusion detection systems (IDS) built with machine learning can classify these threats with high accuracy when training and test data come from the same benchmark dataset [1], [11].

But datasets differ. WSN-DS [2] models LEACH routing protocol attacks in sensor networks. CIC-IoT-2023 [3] captures TCP/UDP flow-level attacks. Edge-IIoTset [4] records multi-protocol industrial IoT traffic. A model trained on one dataset sees feature distributions that may not appear in others.

Our contributions:
1. A 3×3 cross-dataset transfer matrix
2. Behavioral feature mapping (20 features)
3. WSN-to-Edge transfer: 11.9% → 80.7%
4. Two-domain DANN: 96.3-96.5% accuracy
5. Log normalization: 56.8% → 94.4%

III. Datasets

WSN-DS: 374,661 records from NS-2 LEACH simulation. Routing-layer metrics (ADV_S, DATA_S, energy). Attacks: Blackhole, Grayhole, Flooding, TDMA.

CIC-IoT-2023: 199,060 records (stratified). Transport-layer flow statistics. 34 attack types including DDoS, Mirai, MITM, recon.

Edge-IIoTset: 157,800 records. TCP/MQTT/Modbus/ICMP headers (35 usable features). 14 attack types.

All mapped to 5 classes: Normal, Jamming, Spoofing, DoS, Intrusion.

IV. Methodology

A. Behavioral Features

20 protocol-agnostic features: volume, rate, send/receive ratio, timing, burstiness, port diversity, flag intensity, etc.

B. Preprocessing

x' = sign(x) × log(1 + |x|)

Followed by RobustScaler. Sequences: T=5 timesteps.

C. Baseline: RF + XGBoost

D. Hybrid CNN-BiLSTM-Attention

Architecture: Conv1D (32→64) → BiLSTM (128 hidden, 2 layers) → Self-Attention → Dense (256→128→5).

E. Domain Adversarial (DANN)

Gradient reversal layer: multiply by -α during backprop. Alpha schedule:

α = 2/(1 + exp(-5p)) - 1

Pre-training: 8 epochs (α=0), then 25 epochs adversarial.

F. Calibration

Temperature scaling: minimize NLL of softmax(logits/T). ECE measured with 15 bins.

VI. Discussion

Cross-dataset IDS transfer depends more on feature-layer compatibility than model architecture. WSN-DS and Edge-IIoT share behavioral signals (volume, rate, burstiness) enabling 80.7% transfer. CIC-IoT shares transport features with Edge but not routing with WSN.

DANN works when domains share structural overlap (CIC + Edge: both have TCP/UDP features). It fails when they don't (adding WSN: routing metrics have no analog).

The log normalization finding suggests many IDS accuracy numbers may be sensitive to unreported preprocessing. A 37.6-point swing from one line of code should concern researchers.

Limitations: WSN-DS uses simulated NS-2 traffic. CIC-IoT subsampled from 46.7M to 199K. Mitigation responses are simulated. Spoofing class has only 1,214 samples.

VII. Conclusion

We measured the cross-dataset domain gap in wireless IDS across three benchmarks and found it averages 78.8 percentage points for RF classifiers. A hybrid CNN-BiLSTM-Attention model reduces this gap substantially for protocol-compatible datasets, with WSN-to-Edge transfer reaching 80.7%. Domain adversarial training achieves 96.3-96.5% jointly across CIC-IoT and Edge-IIoT. Log-scale feature normalization contributed more to accuracy than any architectural change.

For researchers building IDS systems: report cross-dataset transfer numbers alongside same-dataset accuracy. A 99% accuracy number from a single-dataset evaluation tells you nothing about deployment performance.
